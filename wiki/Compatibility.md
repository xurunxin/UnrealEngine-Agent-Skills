# Compatibility

- **UE5.8.1:** source-verified target; native MCP Skills enabled.
- **UE5.4–5.7:** core development Skills; native MCP Skills disabled.
- **UE5.0–5.3:** migration analysis only.
- **UE4:** legacy intent only, never a direct implementation template.

The detailed policy is maintained in [`docs/compatibility-policy.md`](../docs/compatibility-policy.md).
