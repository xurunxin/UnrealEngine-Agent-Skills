# Roadmap

## 0.1 — foundation

- UE5.4+ compatibility contract;
- UE5.8.1 MCP and AgentSkill source map;
- core C++, Blueprint, module, build, testing, and migration Skills;
- offline validators and a read-only MCP probe.

## Next candidates

- platform-specific packaging Skills for Windows, Linux, Android, and consoles where licensing permits;
- Gameplay Ability System, Mass, StateTree, PCG, Niagara, Sequencer, UMG, and dedicated-server domain Skills;
- version probes for future UE5.8 patches and UE5.9;
- automated publication of `wiki/` and release archives;
- evaluation fixtures that score an Agent on version selection, module dependencies, Blueprint safety, and MCP privilege handling.

A candidate becomes a Skill only when it has a distinct trigger, enough recurring decisions, and a validation path. Otherwise it remains a reference inside an existing Skill.
