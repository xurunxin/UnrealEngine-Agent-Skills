# Examples Directory Instructions

- Examples are original, minimal, and intentionally narrow.
- They must show UE5.4+ conventions and clearly gate UE5.8-only APIs.
- Do not include generated files, binaries, `.uasset`, `.umap`, or copied Engine source.
- Example Toolsets should default to read-only operations and structured return types.
- Keep module dependencies explicit and avoid `BuildSettingsVersion.Latest`.
